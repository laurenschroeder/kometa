Users and position

  • Content surrounds the visitor and appears overhead, so they turn in place.
  • Everything is within arm's reach, so seated and limited-mobility visitors can play.

Visitor flow

  • Fit, ~1 min: the attendant fits the headset.
  • Reset, ~1 min: the ending's Main Menu button returns to the start screen.
  • About 4 visitors per station per hour.

Technical requirements

Headset

Current system software. Performance-tested on Quest 3 at its native 72 fps.

Launch

Open kometa.quest in the headset browser and select Enter VR. Bookmark it on each headset; accept any permission prompt on first launch.

Network

Wi-Fi to load: about 50 MB on first launch, cached after. The live comet counter also uses it; the game plays fully without it.

Input

Pinch with hands, or trigger on controllers. Turn on hand tracking in headset settings.

Audio

Spatial sound and music on the headset speakers. Headphones recommended in loud venues.

Power

About 2 hours per charge. Rotate spares, or use battery straps or cables between sessions.

Special features

  • Shared counter: the start menu shows how many comets all players have released; every visitor adds to it.
  • Audience view: cast each headset to a nearby screen with Quest's built-in casting so the queue can watch.

Comfort and content

  • No artificial locomotion, keeping motion sickness risk low.
  • Mild themes of death and grief in one storyline, stylized and non-graphic. Age guidance follows Meta (10+).
